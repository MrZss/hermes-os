# Hermes Console UI

这是 Hermes Console 的 Electron + React 桌面客户端源码目录。

宗旨：一键安装 Hermes，并用最少步骤完成 AI 供应商、消息平台和运行环境配置。

English: One-click Hermes installation and guided configuration for AI providers, messaging platforms, and runtime environments.

## 常用命令

```bash
npm ci
npm run desktop:dev
npm run build
npm run pack:all
```

完整项目说明、贡献指南和开源政策请查看仓库根目录 [README.md](../README.md)。
