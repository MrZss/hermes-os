重要前提：

一、产品定位保持不变
Hermes Console 是一款桌面客户端，用于安装、连接、配置、聊天、管理和运维 Hermes Agent。
它不是：
- 通用 AI 聊天软件
- 代码 IDE
- 臃肿的服务器管理后台

它应该是：
- 极简、高级、安静、可信赖的桌面控制台
- 面向开发者、AI 重度用户、会使用本地环境或 SSH 远程服务器的用户
- 更像高端桌面生产力工具，而不是网页管理系统

二、固定边界，不允许改动
- 桌面客户端，首发面向 macOS 和 Windows
- Windows 本地运行基于 WSL2
- 远程目标只支持通过 SSH 连接 Linux 服务器
- 同时支持 Native 安装和 Docker 安装
- 默认安全模型为 localhost + SSH 隧道
- 不把公网暴露端口作为默认路径
- 支持多个实例
- 支持多个档案（Profile）
- 支持提供商、集成、会话、日志、诊断、备份、恢复、更新、高级面板

三、本轮最重要目标
请把当前 Hermes Console 从“已经能验收和开发”的设计稿，提升为“可冻结给前端作为第一版正式 UI 基线”的程度。

这轮的重点不是扩页面，而是：
- 中文统一
- 密度优化
- 组件统一
- 向导收口
- 视觉主次更清楚

- SOCKET / WEBHOOK 型 -> Socket / Webhook 型

- Warning -> 警告

- INACTIVE -> 未激活

- Instance = 实例

- Provider = 提供商
- Integration = 集成
- Session = 会话
- Backup = 备份

- Gateway = 网关
- Diagnostics = 诊断
- Advanced Dashboard = 高级面板

要求：

- 可以保留少量技术名词如 OAuth、Endpoint、SSH、Docker、API
- 不要再出现中英并列标题
- 设置页中语言切换为唯一控制入口
- 侧边栏底部不再保留 EN / 中 快捷切换
