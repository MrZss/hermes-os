# Hermes Console 工作台卸载入口设计

## 背景

当前 Hermes Console 已在设置页补齐全局卸载危险区：`gateway uninstall`、`hermes uninstall --yes`、`hermes uninstall --full --yes`。实例级销毁仍在「备份」页。用户反馈“怎么卸载”需要直接加到工作台中，说明入口发现成本过高。

## 设计判断

- 工作台只做指引和跳转，不直接执行卸载，避免把危险操作做成首页快捷按钮。
- 卸载路径分三类展示：实例清理、Gateway 服务卸载、Hermes Agent 卸载。
- 文案必须短，符合此前“副标题不要过多”的要求。
- 视觉上保持 Console 现有卡片风格：低饱和背景、细边框、红色只用于危险语义。

## 推荐方案

### 全局工作台卡片

在首页右侧「继续最近实例」下增加「卸载与清理」卡片，包含三条短步骤：

1. 实例清理：进入最近实例备份页，移除导入实例或销毁本地/远程实例。
2. Gateway 服务：前往设置页诊断与维护，卸载后台服务。
3. Hermes Agent：前往设置页危险区，通过官方卸载向导执行。

操作按钮：

- `前往全局卸载`：跳转 `/settings`。
- `实例清理`：最近实例存在时跳转 `/instance/:id/backups`，否则置灰。

### 实例工作台卡片

在实例概览右栏增加「清理与卸载」卡片：

- 提醒当前实例的删除/销毁在备份页。
- 提醒 Hermes Agent / Gateway 服务卸载在设置危险区。
- 提供 `实例清理` 与 `全局卸载` 两个跳转按钮。

## 非目标

- 不在工作台直接执行任何卸载命令。
- 不新增第三套确认弹窗。
- 不改变既有设置页危险区和备份页销毁逻辑。

## 验收标准

- 首页可直接看到「卸载与清理」入口。
- 实例概览可直接看到「清理与卸载」入口。
- 首页卡片能跳转设置页和最近实例备份页。
- 实例概览卡片能跳转当前实例备份页和设置页。
- 构建通过，桌面客户端可启动，页面不空白。
