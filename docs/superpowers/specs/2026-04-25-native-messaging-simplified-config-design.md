# Hermes Console 原生消息平台傻瓜式配置方案

日期：2026-04-25

## 背景

集成页已收敛为 Hermes 原生消息平台，但每个平台的环境变量过多。用户期望“主打傻瓜式配置”，当前阶段不应把白名单、端口、频道、策略字段暴露给新手用户。

## 设计原则

- 默认只保留最小可用的必填字段。
- 选填字段本阶段不进入 UI；后续确需开放时再按平台单独设计。
- Secret 字段留空表示保持现有值。
- 保存时只写入必填字段；避免误清空或写入无意义空值。

## 必填字段

- Telegram：Bot Token + 用户 ID（`TELEGRAM_ALLOWED_USERS`）
- 微信 / Weixin：账号 ID + Token
- QQ：App ID + Client Secret
- 飞书 / Lark：App ID + App Secret

本阶段只保留以上 4 个平台，避免一次性暴露过多平台与字段。

## UI 行为

- 抽屉标题仍为集成详情。
- 表单区改名“傻瓜式配置”。
- 必要字段带“必填”标记。
- 不展示选填字段入口，降低配置分叉。

## 验收标准

- 集成页源码通过 simpleFields 渲染必填字段。
- 集成页源码不出现历史高级配置分支变量或展示文案。
- Telegram allowed users 保持必填。
- 默认页面文案说明“傻瓜式配置”。
- 测试、构建和客户端页面验收通过。
