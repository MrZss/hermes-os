# Hermes Console 主页与侧栏导航整理设计

## 背景

当前桌面客户端在顶栏、侧栏、主页头部和空状态中都出现新建实例入口，主界面显得重复。侧栏未选中实例时仍展示「当前实例」卡片和「工作区」标题，容易让用户误解已经进入某个工作上下文。

## 目标

- 主界面只保留主页头部一个「新建实例」按钮。
- 根导航「概览」改为「主页」，主页页面标题也改为「主页」。
- 未选中实例时，侧栏不展示「当前实例」卡片。
- 未选中实例时，侧栏第二组标题为「实例列表」，用于从主页语义选择实例。
- 选中实例后，侧栏第二组标题变为「工作区」，只展示当前实例的工作区导航。
- 切换实例必须回到主页选择，不在侧栏当前实例卡片里做下拉切换。

## 设计方案

1. RootLayout 顶栏删除全局「新建实例」按钮；未选中实例的侧栏列表底部也删除「新建实例」。
2. Dashboard 主页保留 PageHeader 里的一个「新建实例」按钮；空状态只保留导入现有 Hermes，不再重复创建按钮。
3. RootLayout 控制台主导航将 `概览` 改为 `主页`。
4. Dashboard PageHeader 标题改为 `主页`，兜底/返回文案中涉及根页面的「概览」逐步改为「主页」。
5. RootLayout 中「当前实例」区只在有 activeInstance 时展示；展示为静态状态卡，不提供切换暗示。
6. RootLayout 工作区标题动态显示：`activeInstance ? "工作区" : "实例列表"`。

## 验收标准

- 主页首屏只看到一个「新建实例」按钮。
- 根侧栏显示「主页」，不再显示根级「概览」。
- 未进入实例路由时侧栏不显示「当前实例」区。
- 未进入实例路由时侧栏列表标题为「实例列表」。
- 进入实例路由后侧栏列表标题为「工作区」。
- 进入实例路由后侧栏不提供实例切换下拉；要切换实例必须点「主页」回到实例列表。
