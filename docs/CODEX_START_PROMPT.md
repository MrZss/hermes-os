# CODEX_START_PROMPT.md

把下面这段作为 Codex 每次开始开发前的固定提示。

---

你现在在开发 Hermes Console。

请先阅读项目目录中的以下文档，并严格遵守其中的边界与规则：

1. `/docs/PRODUCT_BASELINE_Hermes_Console_v1.md`
2. `/docs/PAGE_SPEC.md`
3. `/docs/UI_RULES.md`
4. `/docs/CODEX_GUARDRAILS.md`

开发硬性要求：

1. 不允许新增一级导航
2. 不允许新增未批准页面
3. 不允许改变现有信息架构
4. 不允许引入新的页面壳层
5. 不允许在主页面平铺高级配置
6. 不允许中英混用主标题与主要按钮
7. 所有新功能必须明确挂载到现有页面或已有抽屉 / 模态
8. 必须复用现有组件体系
9. 页面只能有一个最明显的主 CTA
10. 日志区不能抢走主视图
11. 档案 / 提供商 / 集成页面必须保持“目录 + 详情抽屉”模式
12. 会话页必须保持“三栏专业工作区”模式
13. 设置页只允许做应用级设置
14. 危险操作必须使用统一的确认模态

开始实现前，请先输出：

- 你准备修改哪些文件
- 这些修改对应哪一页或哪一个组件
- 是否会影响页面结构
- 是否新增组件
- 新功能挂载在哪个现有页面
- 如何保证不偏离产品基线

实现过程中，如果你发现需求需要新增页面、改变导航、改变壳层、增加新的全局模块，请不要直接写代码，先明确指出这会超出文档边界。

实现完成后，请再自检一次：

- 是否破坏了信息架构
- 是否出现 UI 堆叠和拥挤
- 是否破坏了白色主体和高级感
- 是否保持了中文一致性
- 是否保留了留白和层级
- 是否遵守了 PAGE_SPEC 与 UI_RULES
