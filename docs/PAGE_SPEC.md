# PAGE_SPEC.md

> 用途：逐页锁定 Hermes Console v1 的页面职责、结构边界、状态要求和交互要求。  
> 适用对象：Codex、前端开发、设计还原、产品验收。  
> 原则：**先看本页能不能挂载功能，再决定写不写代码。**

---

## 0. 全局页面规则

### 0.1 壳层固定，不允许改变
所有核心工作页必须共用同一套桌面壳层：

- 左侧导航
- 顶部工具栏
- 主内容区

不允许：
- 不同页面使用不同壳层
- 私自新增二级侧边栏
- 为单个页面发明新的全屏布局
- 把高级配置塞到主内容区成为常驻模块

### 0.2 一级导航固定
只允许以下 8 个一级导航：

- 概览
- 会话
- 档案
- 提供商
- 集成
- 日志
- 备份
- 设置

不允许新增新的一级导航。任何新功能必须挂载到上面某一页，或者挂到已有抽屉 / 模态中。

### 0.3 页面主 CTA 规则
每个页面只能有 **1 个最明显的主 CTA**。  
其余动作用次级按钮、轻量按钮、菜单项或危险区承接。

### 0.4 页面语言规则
初版以简体中文为主。  
保留必要技术名词，例如：

- SSH
- Docker
- OAuth
- Endpoint
- API

但不允许中英并列标题，比如：

- 档案 (Profiles)
- 显示语言 (Language)

## 1. 欢迎页 / 首次启动页

### 页面目标
帮助用户理解 Hermes Console 是什么，并在首次进入时完成**本地实例**或**远程实例**的创建入口选择。

### 必须包含
- 产品欢迎信息
- 两个主入口：
  - 添加本地实例
  - 添加远程实例
- 本地支持说明：
  - macOS
  - Windows WSL2
  - Docker
- 远程支持说明：
  - 通过 SSH 连接 Linux 服务器
- Native 与 Docker 差异的简要说明
- 默认安全模型说明：
  - localhost
  - SSH 隧道

### 主 CTA
- 添加本地实例  
或
- 添加远程实例  
> 两者可并列，但视觉上只能有一个更强调的默认主入口。

### 允许的辅助区
- 最近活动占位区
- 快速说明卡片
- 官方文档入口（轻量）

### 不允许
- 直接堆大量设置表单
- 在欢迎页显示复杂的日志模块
- 提前展示高级配置
- 用营销页风格替代产品页风格

### 需要覆盖的状态
- 空状态
- 首次安装引导态
- 最近活动为空态

## 2. Dashboard（实例总览）

### 页面目标
作为全局首页，帮助用户快速看到所有实例的状态、最近活动和关键动作。

### 必须包含
- 实例列表或实例卡片区
- 实例状态摘要
- 顶部快捷动作区
- 最近活动或健康摘要区
- 明确的实例切换/进入路径

### 每张实例卡片至少包含
- 实例名称
- 本地 / 远程
- 平台
- 安装方式（Native / Docker）
- Hermes 版本
- 网关状态
- API 状态
- 默认档案
- 最近操作时间

### 页面主 CTA
- 新建实例

### 允许的次动作
- 打开会话
- 查看日志
- 创建备份
- 更新

### 页面结构要求
- 不能只有上半部分有内容、下半部分大片空白
- 状态信息和快捷动作要分区
- 实例卡片信息密度要高于营销展示页，但不能拥挤
- 页面更像控制台首页，而不是展示页

### 不允许
- 把所有功能都堆到首页
- 为了填满页面加入无关业务模块
- 每张实例卡片都放一组同权重大按钮
- 首页出现多个视觉上同权重的主 CTA

### 需要覆盖的状态
- 正常
- 警告
- 离线
- 更新中
- 空状态
- 加载骨架屏
- 连接失败状态

## 3. 创建实例向导

### 页面目标
通过固定的 5 步流程完成 Hermes 实例的创建、配置与部署。

### 流程固定为 5 步
1. 选择目标
2. 环境与连接检查
3. 安装方式
4. 提供商与档案
5. 最终确认与部署

不允许增删步骤，也不允许在一步中平铺所有设置。

---

### Step 1：选择目标

#### 必须包含
- 本地实例
- 远程实例
- 本地说明：macOS / Windows WSL2 / 本机安装
- 远程说明：SSH 连接 Linux 服务器

#### 主 CTA
- 下一步

#### 不允许
- 同时展开复杂设置
- 出现与安装方式重复的过多文案

---

### Step 2：环境与连接检查

#### 页面目标
让用户知道当前环境是否具备部署条件，并能对失败项进行修复或重试。

#### 本地预检建议项
- 操作系统
- 运行服务（可选）
- 工作目录权限
- Hermes 工作目录可写
- 网络访问
- 端口占用

#### 远程预检建议项
- SSH 连通性
- 用户权限
- 可写目录
- 运行服务
- 磁盘空间
- 端口冲突

#### 必须支持的状态
- 通过
- 警告
- 失败
- 可重试
- 修复建议

#### 不允许
- 所有检查项都永远显示通过
- 把预检写成静态说明文
- 不区分本地与远程的检查逻辑

---

### Step 3：部署方式

#### 必须包含
- 本机安装
- 服务器部署

#### 需要表达清楚的差异
- 本机与服务器目标差异
- 可迁移性
- 权限边界
- 适用场景

#### 主 CTA
- 下一步

#### 不允许
- 营销化文案
- 把这一页做成广告式对比卡
- 出现与 Step 1 重复的大段说明

---

### Step 4：提供商与档案

#### 必须包含
- Hermes 官方 provider / model 配置
- Provider 选择
- 模型选择
- 默认档案名称
- 默认档案映射为 Hermes profile
- 按 provider 动态渲染的字段区

#### 交互要求
- Provider 相关字段按官方配置对象动态展开
- 默认档案与 Hermes profile 的映射关系要清晰
- Provider、模型、档案之间的关系要清晰
- 不能让这一步像普通大表单页
- 不把“自动选择”作为新手可选项

#### 不允许
- 在主视图平铺高级配置
- 中英混用表单标题
- 把所有 provider 的所有字段一次性展开

---

### Step 5：最终确认与部署

#### 页面目标
作为最终确认页，完整总结部署信息并启动安装。

#### 必须包含
- 目标类型（本地 / 远程）
- 部署方式（本机安装 / 服务器部署）
- Provider
- 模型
- 默认档案
- 消息接入在集成页配置
- 本地路径或远程主机摘要
- 安全方式（localhost / SSH tunnel）
- 风险说明或关键提示

#### 主 CTA
- 开始安装

#### 不允许
- 只有一个按钮和少量空白
- 缺少部署摘要
- 省略安全方式说明

---

### 部署中（Running）

#### 必须包含
- 当前步骤
- 总进度
- 当前任务
- 实时日志
- 取消 / 重试 / 错误反馈

#### 日志区域要求
- 需要存在，但不能成为整页绝对视觉中心
- 更像受控日志面板，不像纯终端截图
- 黑色日志区域不可过大、过重

---

### 成功（Success）

#### 必须包含
- 实例创建成功的明确反馈
- 当前实例名称
- 本地地址或远程连接方式
- 安全连接方式
- 下一步动作：
  - 进入工作区
  - 打开会话
  - 打开高级面板

#### 不允许
- 让日志区比成功反馈更抢眼
- 成功页继续以终端块为视觉主角

---

## 4. 实例概览页

### 页面目标
展示当前实例的核心状态、快捷操作、健康情况和最近活动。

### 必须包含
- 实例名称
- 本地 / 远程
- 安装方式
- 版本
- 健康状态
- 当前档案
- 当前模型
- SSH 隧道状态（远程时）
- 健康卡片区
- 最近活动或时间线

### 快捷操作允许包含
- 启动
- 停止
- 重启
- 打开会话
- 创建备份
- 更新
- 打开高级面板

### 页面规则
- 只能有一个明显主动作，其余为次动作
- 健康卡片高度、节奏、对齐要一致
- 活动区不能过空
- 不能把“备份”“更新”“高级”都做成同权重主按钮

### 不允许
- 把实例概览页做成操作按钮堆积页
- 在这里展开所有配置表单
- 让时间线成为占位用的空模块

## 5. 会话页

### 页面目标
作为 Hermes Console 的核心工作页，用于进行会话、查看工具调用与上下文状态。

### 布局固定为三栏

#### 左栏
- 会话列表
- 搜索
- 筛选
- 新建会话

#### 中栏
- 对话内容
- 用户消息
- Agent 回复
- 流式生成状态
- 工具调用标记
- 输入区
- 附件入口（如存在）

#### 右栏
- 当前档案
- 当前模型 / Provider
- 上下文信息
- 工具状态
- 会话元数据

### 必须区分的内容类型
- 用户提问
- Agent 回复
- 工具调用
- 日志回显
- 最终结论

### 页面主 CTA
- 新建会话

### 不允许
- 变成消费级 IM 风格
- 使用夸张社交化消息气泡
- 右栏堆满无关信息
- 用黑色大日志块抢走中栏主视图

### 需要覆盖的状态
- 空会话
- 流式生成中
- 工具调用中
- 失败重试
- 无会话历史
- 当前实例离线

## 6. 档案页

### 页面目标
以目录方式管理同一实例下的多个隔离 Hermes profile。

### 必须支持
- 新建档案
- 克隆档案
- 重命名
- 删除
- 导出
- 导入
- 设为默认

### 每张档案卡片至少包含
- 名称
- provider / model 摘要
- 会话数量
- gateway status
- 最近使用时间
- 默认状态

### 页面必须强调
- 档案是相互隔离的环境
- 档案对应 Hermes profile
- 默认档案更清晰
- 动作区更规范，不是散落文字链接

### 主 CTA
- 新建档案

### 不允许
- 中英并列标题
- 卡片尺寸和节奏混乱
- 将全部编辑字段平铺在列表页

### 需要覆盖的状态
- 默认档案
- 非默认档案
- 正常
- 异常
- 删除确认模态
- 克隆模态

## 7. 提供商页

### 页面目标
以目录方式管理 Hermes 官方 model/provider 配置。

### 页面结构
- 当前 AI 接入摘要
- 提供商目录
- 详情抽屉

### 排序建议
- 已配置 / 当前 provider
- 新手常用 provider
- 其他官方 provider

### 卡片字段
- 名称
- 状态
- 配置方式
- 推荐模型
- 管理入口

### 列表页规则
- 列表页负责扫描与快速定位
- 详情抽屉负责“登录或粘贴 Key → 保存 → 测试”
- 字段按 provider 动态渲染，不做统一大表单
- 不展示内部自动选择 provider

### 详情抽屉必须允许配置
- 认证方式
- 默认模型
- 必填凭据 / Endpoint
- 测试连接

### 必须支持状态
- 已连接
- 未完成
- 错误
- 未启用

### 页面规则
- 更像可扩展目录，不像品牌陈列页
- 抽屉承担详情，列表页承担扫描
- 搜索/筛选要轻量，不能变复杂后台
- 新手路径必须足够短：选供应商 → 登录或粘贴 Key → 保存 → 测试

### 不允许
- 大量散落品牌卡片
- 中英混用分组标题
- 列表页平铺全部配置字段
- 所有 provider 使用同一套字段模板

## 8. 集成页

### 页面目标
以目录方式管理 Hermes 原生消息平台。集成页只呈现聊天/消息平台接入，不再承载程序化访问、编辑器协议、自动化回调或扩展入口。

### 页面结构
- 原生消息平台目录
- 集成卡片区
- 详情抽屉
- profile 选择器

### 分组建议
- Telegram
- 微信 / Weixin
- QQ
- 飞书 / Lark

### 卡片字段
- 图标
- 名称
- 状态
- 接入类型
- 健康状态
- 运行模式

### 详情抽屉必须允许配置
- 必填字段配置
- 敏感字段空值保持原值
- 保存配置
- 状态说明

### 必须支持状态
- 已启用
- 未启用
- 异常
- 活跃
- 未同步

### 不允许
- 做成应用商店风格
- 平铺复杂配置
- 状态标签体系混乱
- 把 Skills / Plugins 当作集成页核心对象
- 把程序化访问、编辑器协议、自动化回调或智能家居入口放入集成页
- 在详情抽屉内放实例启停、运行态重启等维护操作

## 11. 设置页

### 页面目标
只承载应用偏好、Hermes 配置摘要与维护入口。

### 只允许包含
- 语言
- 主题
- Hermes 配置摘要
- 维护入口
- 打开高级面板入口

### 页面规则
- 语言切换只保留这一个入口
- 不在侧边栏底部再放第二个语言入口
- 整体更像应用偏好，不像杂项堆叠页
- 不承担实例级或部署级伪全局配置

### 不允许
- 将 Hermes 高级配置全部塞到设置页
- 页面同时出现多套语言控制入口
- 中英混合字段名
- SSH 默认项、安装偏好、日志偏好这类旧入口

1. App Shell（左侧导航 + 顶部工具栏 + 主内容区）
2. Dashboard
3. 创建实例向导
4. 实例概览页
5. 会话页
6. 档案页
7. 提供商页
8. 集成页

10. 备份页
11. 设置页
12. 抽屉 / 模态 / 状态页统一收口

## 15. 最终原则

如果出现“功能需要加，但不知道加在哪里”的情况，先判断：

1. 能否挂到已有一级页面？
2. 能否挂到已有抽屉/模态？
3. 会不会破坏实例 → 档案 → 工作区这条主结构？
4. 会不会新增新的信息层级？

只要这 4 个问题里有一个回答不清楚，先不要写代码，先更新文档。
